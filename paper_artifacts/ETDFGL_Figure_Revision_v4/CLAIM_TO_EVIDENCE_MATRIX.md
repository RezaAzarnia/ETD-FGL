# ETD-FGL Claim-to-Evidence Traceability Matrix (Revision v4)

**Document Purpose:** Rigorous audit matrix linking every quantitative claim, mathematical formula, empirical metric, and proposed mechanism in the ETD-FGL research project to its exact code file, line range, and verified experimental result file.

### Audit Classification Scheme (Revision v4 Standard):
- **Verified:** Direct empirical observations, calculated quantities, algorithm formulas mapped to frozen code, verified SHA-256 hashes, and verified checkpoint files on disk.
- **Hypothesis:** Proposed theoretical mechanisms, structural explanations, and architectural conjectures where underlying causal logs were not directly recorded (e.g., DMGNN-FL edge pruning count, PubMed citation sparsity hypothesis, Reddit Seed 43 degree variance hypothesis).
- **Not verified:** Unsubstantiated generalizations, claims not supported by experimental records, or metadata absent from per-run summary JSON files (e.g., GPU hardware model).
- **Not Recorded:** Metrics where raw evaluation arrays were not serialized to scalar summary files (e.g., F1-score, Precision, Recall).
- **Not Measured / Excluded:** Metrics outside the scope of federated graph learning (e.g., Differential Privacy $\epsilon$, IoT Packet Delivery Ratio).
